# Atelier Manager

아틀리에에서 구매한 상품을 Unity 안에서 바로 받고 설치하는 도구예요.

## 설치

Unity 2019.4 이상에서 아래 중 하나로 설치하세요.

- **Package Manager**: Window ▸ Package Manager ▸ + ▸ Add package from git URL… 에 `https://github.com/StudioRaming/Onairdeck-Unity-Manager.git` 입력 (Git 필요)
- **unitypackage**: [Atelier-Manager.unitypackage](https://github.com/StudioRaming/Onairdeck-Unity-Manager/releases/latest/download/Atelier-Manager.unitypackage) 를 받아 Assets ▸ Import Package ▸ Custom Package… 로 가져오기
- **VCC**: https://studioraming.github.io/atelier-package-manager/

## 사용

1. Window ▸ Atelier Manager 를 열어요.
2. **Sign in with browser** 로 아틀리에 계정에 로그인해요.
3. 구매 목록에서 **Download** 를 눌러요.

## English

A Unity tool to download and install the products you bought on Atelier.

**Install** (Unity 2019.4 or newer), one of:

- Package Manager ▸ + ▸ Add package from git URL… ▸ `https://github.com/StudioRaming/Onairdeck-Unity-Manager.git` (needs Git)
- [Atelier-Manager.unitypackage](https://github.com/StudioRaming/Onairdeck-Unity-Manager/releases/latest/download/Atelier-Manager.unitypackage) ▸ Assets ▸ Import Package ▸ Custom Package…
- VCC: https://studioraming.github.io/atelier-package-manager/

**Use**: open Window ▸ Atelier Manager, click **Sign in with browser**, then **Download** in your purchase list.

**Contact**: https://atelier.io.kr/contact

## 日本語

アトリエで購入した商品を、Unityの中でそのままダウンロード・インストールできるツールです。

**インストール**（Unity 2019.4以上）、次のいずれか:

- Package Manager ▸ + ▸ Add package from git URL… に `https://github.com/StudioRaming/Onairdeck-Unity-Manager.git` を入力（Gitが必要）
- [Atelier-Manager.unitypackage](https://github.com/StudioRaming/Onairdeck-Unity-Manager/releases/latest/download/Atelier-Manager.unitypackage) を Assets ▸ Import Package ▸ Custom Package… でインポート
- VCC: https://studioraming.github.io/atelier-package-manager/

**使い方**: Window ▸ Atelier Manager を開き、**Sign in with browser** でサインインして、購入一覧の **Download** を押します。

**お問い合わせ**: https://atelier.io.kr/contact
